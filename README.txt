Diese Seite ist eine einzige Startseite (index.html) plus
Bilder/Videos (Ordner "assets"), Logo und zwei Rechtsseiten.


──────────────────────────────────────────────
A) ERST LOKAL TESTEN (ohne Internet, am eigenen PC)
──────────────────────────────────────────────

1. Entpacke die ZIP-Datei komplett in einen Ordner.
2. Doppelklick auf "index.html".
   → Die Seite öffnet sich im Browser.

Wichtig: Der Ordner "assets" und "logo.png" MÜSSEN
im selben Ordner liegen wie "index.html".
Wenn du Dateien einzeln verschiebst, fehlen Bilder/Videos.


──────────────────────────────────────────────
B) BEI GITHUB HOCHLADEN (Seite live schalten)
──────────────────────────────────────────────

Voraussetzung: kostenloser GitHub-Account (github.com).

1. Oben rechts auf "+"  →  "New repository".
2. Repository-Name z. B.:  bella-website
   → "Public" auswählen  →  "Create repository".

3. Auf der neuen Seite:  "uploading an existing file" anklicken
   (Link steht mitten im Text).

4. Ziehe ALLE Dateien UND den Ordner "assets" ins Fenster:
      • index.html
      • impressum.html
      • datenschutz.html
      • logo.png
      • .nojekyll
      • den kompletten Ordner "assets"
   Tipp: Am einfachsten markierst du alles im entpackten
   Ordner und ziehst es in einem Rutsch hinein.

5. Unten "Commit changes" klicken.

6. Oben im Menü:  "Settings"  →  links "Pages".
   Bei "Branch":  "main"  auswählen  →  "Save".

7. Warte 1–2 Minuten, lade die Seite neu.
   Oben erscheint deine Adresse, etwa:
      https://DEINNAME.github.io/bella-website/


──────────────────────────────────────────────
C) WAS DU NOCH EINTRAGEN MUSST (vor dem echten Start)
──────────────────────────────────────────────

Öffne index.html in einem Text-Editor und suche nach dem
Zeichen  ◆  – dort stehen alle Stellen zum Anpassen:

  • LINKS (ganz wichtig): im Script-Bereich das Objekt
    "LINKS" – trage dort deine echten Adressen ein:
        telegramKanal   = dein kostenloser Telegram-Kanal
        telegramAnfrage = deine persönliche Anfrage / Gruppe
        onlyfans        = dein OnlyFans-Link
        barefootDiary   = dein Barefoot-Diary-Zugang

  • IMPRESSUM (impressum.html) vollständig ausfüllen
  • DATENSCHUTZ (datenschutz.html) vollständig ausfüllen
  • FIRMENNAME im Footer (US LLC)

Rechtlicher Hinweis: Impressum, Datenschutz, EU-Vertreter
(Art. 27 DSGVO) und die Altersthematik solltest du vor dem
Live-Gang von einer Fachanwält:in prüfen lassen.


──────────────────────────────────────────────
D) EIGENE DOMAIN (optional, später)
──────────────────────────────────────────────

Wenn du z. B. "bellabarfuss.de" statt der github.io-Adresse
willst: Domain kaufen, dann in GitHub unter Settings → Pages
→ "Custom domain" eintragen und beim Domain-Anbieter einen
CNAME-Eintrag auf DEINNAME.github.io setzen. Sag Bescheid,
dann gehen wir das zusammen durch.
